# เวทีหมอลำออนไลน์ 3 มิติ สำหรับ TikTok LIVE

หน้าเว็บเวทีหมอลำ 3 มิติ ที่ดึง **รูปโปรไฟล์ + ชื่อ** ของคนที่เข้ามาดูไลฟ์ TikTok
มาเป็นตัวละครเต้นอยู่ในงาน รูปโปรไฟล์อยู่ในกรอบกลมบนหัวตัวละคร

- ตัวละคร ทรงผม ชุด (ชุดไทยสไบ, เสื้อลายดอก, ม่อฮ่อม+ผ้าขาวม้า, กระโปรงระบาย, หางเครื่อง, สูทลูกทุ่ง) และท่าเต้น **สุ่มทั้งหมด** ผู้เล่นเลือกเองไม่ได้
- คนมาใหม่ยืน **ลานด้านล่างแถวหลัง** ยิ่งกดใจมากยิ่งได้ขยับมาแถวหน้าติดเวที (รอขึ้นเวที)
- **ขึ้นเวทีแบ่งโควต้าครึ่ง ๆ**: ครึ่งหนึ่งให้คนส่งของขวัญมากสุด อีกครึ่งให้คนกดใจมากสุด (ฝั่งไหนคนไม่พอ อีกฝั่งใช้แทน) ที่ 1 ของแต่ละสายได้ 👑
- คนที่ไม่ดูต่อ → **วาร์ปหายไป** แล้วคนอันดับถัดไปขึ้นมาแทน

## วิธีใช้แบบง่าย (รันบนคอมตัวเอง)

1. ติดตั้ง [Node.js](https://nodejs.org) รุ่น LTS (ครั้งเดียว)
2. ดาวน์โหลดโค้ดนี้เป็น ZIP แล้วแตกไฟล์
3. ดับเบิลคลิก **`start.bat`** (Windows) หรือ **`start.command`** (Mac) — ครั้งแรกจะติดตั้งให้เอง แล้วเปิดเบราว์เซอร์ที่ `http://localhost:3000`
4. เริ่มไลฟ์ใน TikTok LIVE Studio ก่อน แล้วกด ⚙ → "เชื่อมต่อ TikTok LIVE" ใส่ชื่อบัญชีของคุณ
5. ใน LIVE Studio เพิ่มแหล่งภาพแบบลิงก์เว็บ `http://localhost:3000/?clean=1` หรือจับภาพหน้าต่างเบราว์เซอร์

## วิธีใช้ (พิมพ์คำสั่งเอง)

```bash
npm install
npm start            # เปิด http://localhost:3000  (เริ่มด้วยโหมดทดลอง มีผู้ชมจำลอง)
```

1. เปิดหน้าเว็บ กดปุ่ม ⚙ มุมขวาล่าง (โผล่เมื่อเลื่อนเมาส์เข้ามา)
2. ใส่ชื่อผู้ใช้ TikTok ที่ **กำลังไลฟ์อยู่** แล้วกด "เชื่อมต่อไลฟ์"
3. ใน TikTok LIVE Studio / OBS เพิ่ม Browser Source ขนาด 1080×1920 ชี้ไปที่
   `http://localhost:3000/?clean=1` (`clean=1` = ซ่อนปุ่มตั้งค่า)

หรือกำหนดตั้งแต่ตอนรัน: `TIKTOK_USERNAME=ชื่อผู้ใช้ npm start`

### ตั้งค่าในแผง ⚙

- **ชื่อบนป้ายเวที** — พิมพ์ข้อความอะไรก็ได้ (สูงสุด 80 ตัวอักษร) ป้ายเปลี่ยนทันที
- **มุมกล้อง** — ลากบนจอ = หมุน, ล้อเมาส์/ถ่างนิ้ว = ซูม, คลิกขวาลาก = เลื่อน หรือกดปุ่มในแผง (ซูมเข้า-ออก, หมุนซ้าย-ขวา, ก้ม-เงย, เลื่อนซ้าย-ขวา-ขึ้น-ลง-หน้า-หลัง, รีเซ็ต)
  มุมกล้องส่งถึงทุกหน้าจอที่เปิดเว็บนี้อยู่ จึงปรับจากเบราว์เซอร์ปกติแล้วจอใน OBS/LIVE Studio เปลี่ยนตาม
- **ขนาดและฉากเวที** — ปรับความกว้างเวที 8–22 เมตร (จำนวนคนบนเวทีสูงสุดเพิ่มตามความกว้าง) และเลือกฉากได้ 4 แบบ: กนกชมพู-ทอง, พญานาคน้ำเงิน-ทอง, เพชรทองม่านแดง, จันทร์แดง
- **บูทร้านของกิน** — 6 ร้านสองข้างลาน ตัวละครที่เต้นเหนื่อยจะสุ่มเดินไปกินแล้วกลับมาเต้นต่อ
  ชื่อร้านพิมพ์เองได้ (เช่น ชื่อคนที่จองเช่า) เลือกจากชื่อบัญชีผู้ชมในไลฟ์ได้ หรือเปิดโหมดอัตโนมัติให้ผู้ส่งของขวัญสูงสุด 6 คนได้เป็นชื่อร้าน
- **ขนาดรูปโปรไฟล์**, **จังหวะ BPM**, จำนวนคนบนเวที, เวลาที่ถือว่าไม่ดูต่อ
- ค่าทั้งหมดถูกจำไว้ในไฟล์ `settings.json` ปิดเปิดโปรแกรมใหม่ค่าไม่หาย

### ตัวเลือก

| ที่ | ค่า | ความหมาย |
| --- | --- | --- |
| URL | `?clean=1` | ซ่อนปุ่มตั้งค่า |
| URL | `?bpm=128` | ความเร็วจังหวะเต้น ให้ตรงกับเพลงที่เปิด |
| URL | `?bloom=0` | ปิดแสงฟุ้ง (ถ้าเครื่องช้า) |
| env | `TIKTOK_USERNAME` | เชื่อมต่อไลฟ์อัตโนมัติ |
| env | `STAGE_TITLE` | ข้อความบนป้ายเวที |
| env | `IDLE_TIMEOUT` | เงียบกี่วินาทีถือว่าไม่ดูต่อ (ค่าเริ่มต้น 180) |
| env | `MIN_STAGE_SECONDS` | ต้องดูกี่วินาทีก่อนมีสิทธิ์ขึ้นเวที (30) |
| env | `ADMIN_KEY` | ตั้งรหัสสำหรับแผงตั้งค่า (ควรตั้งถ้าเปิดเว็บสู่สาธารณะ) |
| env | `EULER_API_KEY` | คีย์ Euler Stream (ไม่บังคับ ช่วยเพิ่มโควตาการเชื่อมต่อ) |

คะแนน: ดู 1 วินาที = 1, กดใจ = 0.5, คอมเมนต์ = 3, แชร์ = 15, ติดตาม = 20, ของขวัญ = 10 ต่อเหรียญ (แก้ได้ที่ `cfg` ใน `server.js`)

## ข้อจำกัดที่ควรรู้

- TikTok **ไม่ส่งสัญญาณตอนคนออกจากไลฟ์** มีแต่ตอนเข้า กดใจ คอมเมนต์ ส่งของขวัญ
  ระบบจึงถือว่า "ไม่ดูต่อ" เมื่อเงียบเกิน `IDLE_TIMEOUT` คนที่ดูเฉย ๆ ไม่กดอะไรเลยจะหายไปเมื่อครบเวลา
  (แนะนำบอกคนดูว่า "กดใจไว้ ตัวละครจะไม่หาย")
- การเชื่อมต่อใช้ไลบรารีไม่เป็นทางการ [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector) อาจหลุดหรือใช้ไม่ได้เมื่อ TikTok เปลี่ยนระบบ
- ต้องรันบนเครื่องที่เปิดค้างได้ (คอมที่ใช้ไลฟ์, VPS, Railway, Render ฯลฯ) — **ใช้กับ Vercel ไม่ได้** เพราะต้องมีเซิร์ฟเวอร์ที่เชื่อมต่อค้างไว้

## โครงสร้าง

- `server.js` — เชื่อมต่อไลฟ์, คิดคะแนน/อันดับ, ส่งสถานะผ่าน WebSocket
- `public/stage.js` — เวที ทรัส ฉากลายกนก ไฟ ลำแสง
- `public/character.js` — ตัวละครสุ่ม + ท่าเต้น + เอฟเฟกต์วาร์ป
- `public/main.js` — กล้อง, กรอบรูปโปรไฟล์/ชื่อ, แผงตั้งค่า

## แผงควบคุมด้านซ้าย และโหมดทดสอบ / โหมดรันจริง

- เปิด `http://localhost:3000` บนคอม แผงควบคุมจะอยู่ด้านซ้าย ภาพเวทีแนวตั้ง 9:16 อยู่ด้านขวา (บนมือถือแผงจะเป็นแผ่นด้านล่าง)
- แท็บ **🚀 เริ่มไลฟ์** เลือกโหมด
  - **🧪 โหมดทดสอบ** ไม่ต่อ TikTok ใช้ผู้ชมจำลอง
  - **🔴 โหมดรันจริง** ล้างผู้ชมจำลองออก ใส่ชื่อผู้ใช้แล้วกด "เชื่อมต่อไลฟ์"
- แท็บ **🧪 ทดสอบ** (ใช้ได้เฉพาะโหมดทดสอบ) พิมพ์ชื่อผู้ชม แล้วกดจำลอง คนเข้า / ไลก์ x50 / คอมเมนต์ / ติดตาม / แชร์ / คนออก / ส่งของขวัญ เปิดปิด "จำลองผู้ชมอัตโนมัติ" และ "ล้างฉาก" ได้
- ตอนออกไลฟ์ให้ใช้ลิงก์ `http://localhost:3000/?clean=1` ใน LIVE Studio หน้านี้ไม่มีแผงและปุ่ม
- แท็บ **🍢 ร้านค้า** เพิ่มหรือลดจำนวนร้านได้ 0–10 ร้าน (กด "＋ เพิ่มร้าน" หรือ ✕ ท้ายช่องชื่อร้าน)
