# 🎪 tiktokgameee — เกมส์มินิ TikTok LIVE "ขึ้นเวทีเต้น"

เว็บเกมส์ธีม **เวทีคอนเสิร์ตไทย** — คนดู TikTok LIVE เข้ามาแล้ว **กลายเป็นนักเต้นบนเวที** ได้เลย

- คนใหม่เข้ามาดู → **นั่งรอแถวล่างก่อน** (avatar + วงแหวนนับเวลาคอยอยู่)
- ดูไปถึงเกณฑ์ (หรือส่งของขวัญ / กดไลก์ / คอมเมนต์ช่วยเร่ง) → **ขึ้นเวทีเต้น** เล่น confetti + โต๊ะตอบ "🎉 X ขึ้นเวที!"
- บนเวทีแต่ละคน **เต้นเป็นของตัวเอง** — มี 4 แบบเต้น (โยก / กระโดด / เลี้ยว side-step / หมุนตัว) สุ่มเสื้อผ้าและจังหวะให้แต่ละคน ต่างกัน
- ไม่ดูต่อ / ออกจาก LIVE → **ว๊าปหายไป** คนใหม่ที่ถึงอันดับจากคิวย้ายขึ้นมาแทนที่ทันที
- ครบทั้ง: แชทสด ๆ, ไลก์ (หัวใจลอยเมื่อมีไลก์เข้าจริง), แชร์, ติดตาม, ของขวัญ, จำนวนผู้ชม, อันดับผู้ชม, Goal, ภารกิจ

```
┌──────────────────────────────────────────────────────────────┐
│              ◆ tiktokgameee  ◆  👥 927.7K                    │
│  🏆 อันดับผู้ชม                            🎯 Goal (0/6)    │
│  ┌───────────┐   ✦ แสงไฟสาด ✦            ┌───────────┐    │
│  │ แชทสด ๆ   │      เวทีคอนเสิร์ตไทย      │ ภารกิจ    │    │
│  │ ไหลขึ้นมา │   💃🕺 นักเต้น = ผู้ชม      └───────────┘    │
│  └───────────┘                            ┌───────────┐    │
│                                          │  รอขึ้นเวที │    │
│  ⏳ รอขึ้นเวที [avatar][avatar]...  [พิมพ์ชื่อ = เข้าเต้น]  │
└──────────────────────────────────────────────────────────────┘
```

> ตัด UI แบบ TikTok (แถบหัว + แถบกดไลก์/คอมเมนต์ด้านล่าง) ออกหมดแล้ว — เหลือเฉพาะ HUD เกมส์ที่เกี่ยวข้อง

---

## 1) เริ่มเล่นไว ๆ (ไม่ต้องต่อ TikTok จริงก็ได้)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm start
```

แล้วเปิดเบราว์เซอร์ที่

| หน้า | ที่อยู่ |
|---|---|
| 🎪 หน้าเกมส์ (ใช้ออค่า) | http://localhost:3000/ |
| ⚙️ แผงควบคุม | http://localhost:3000/admin |

ตอนแรกระบบจะเปิด **โหมดทดสอบ (Simulator)** ให้เลย — มีผู้ชมปลอมเข้าเกมส์ ดูคนขึ้นเวทีเต้น ดูคนว๊าปหาย ได้ทันที

**เล่นเอง**: พิมพ์ชื่อในช่องด้านล่าง ("พิมพ์ชื่อแล้ว Enter = เข้าเต้น 💃") แล้ว Enter = ชื่อคุณเข้าเกมส์ (เปลี่ยนชื่อถาวรได้ด้วย `!ชื่อ แหยมวย`) — คุณจะอยู่ท้ายคิวก่อน แล้วค่อยๆ ขยับขึ้นเวทีเมื่อคนข้างหน้าถูกโปรโมตหรือออกไป

---

## 2) ต่อ TikTok LIVE จริง

ให้เปิด TikTok LIVE Studio → เพิ่ม **Browser Source** ชี้ไปที่ `http://localhost:3000/` (ขนาด 1920×1080) หรือใช้แชร์หน้าจอทั้งตัว

จากนั้นปิด Simulator ไปที่ `/admin` กรอก `@username` ของช่องที่กำลัง LIVE แล้วกดเชื่อมต่อ

### ต้องมี SIGN_API_KEY (ฟรี)

ไลบรารี่ `tiktok-live-connector` ที่ใช้เชื่อม WebSocket ของ TikTok ต้องใช้บริการเซ็น URL จาก [eulerstream.com](https://www.eulerstream.com) (มีแพ็กเกจฟรี) — เอา key มาใส่ก่อนรัน:

```bash
# วิธี 1: ใส่ใน .env (copy จาก .env.example)
cp .env.example .env      # แล้วแก้ SIGN_API_KEY ในไฟล์

# วิธี 2: ใส่ตอนรัน
SIGN_API_KEY=xxxxxxxx npm start
```

> เครื่องที่รัน `npm start` ต้องออกอินเทอร์เน็ตถึง TikTok ได้ (ไม่ควรใช้เครื่องที่ TikTok บล็อก) และต้องไม่ปิดโปรแกรมระหว่าง LIVE

### เหตุการณ์ที่ดึงมาจาก TikTok ได้

| เหตุการณ์ | เอาไปทำอะไรในเกมส์ |
|---|---|
| คนเข้า LIVE (`member`) | เพิ่มนักเต้นใหม่ ลงคิวด้านล่าง |
| แชท (`chat`) | โชว์ในแชท + ช่วยลดเวลารอขึ้นเวที |
| ไลก์ (`like`) | หัวใจลอยขึ้นหน้าจอ + เพิ่มแรงดันให้ขึ้นเวทีเร็วขึ้น |
| แชร์ (`share`) / ติดตาม (`follow`) | โชว์ในแบนเนอร์ + เพิ่มคะแนน |
| ของขวัญ (`gift`) | **เด้งขึ้นเวทีทันที** + นำไปคำนวณ Goal/อันดับ |
| จำนวนผู้ชม (`roomUser`) | ถ้าจำนวนลดลง = ไล่คนออกตามจำนวนที่หายไป |

## 3) กติกาเกมส์ (ปรับได้ที่ /admin ตอนรันอยู่เลย)

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `watchToStageSeconds` | 10 | ดูครบกี่วินาทีถึงมีสิทธิขึ้นเวที |
| `stageSlots` | 12 | จำนวนช่องบนเวที |
| `queueSlots` | 12 | จำนวนคนที่โชว์ด้านล่าง |
| `giftInstantStage` | เปิด | ส่งของขวัญ = เด้งขึ้นเวทีทันที |
| `likeBoost` / `chatBoost` | 0.05 / 0.5 | 1 ไลก์ / 1 คอมเมนต์ ลดเวลารอ (วินาที) |
| `leaveInactiveSeconds` | 45 | อยู่บนเวทีแล้วเงียบ ๆ นานขนาดนี้ = ถือว่าออกไป |
| `roomUserKick` | เปิด | จำนวนผู้ชมลดลง = ไล่คนออกตาม |

**ระบบจัดอันดับ**: คะแนน = เวลาดู + ไลก์ + คอมเมนต์ + ของขวัญ — เรียงจากมากไปน้อย เวทีว่างช่องไหนก็ดึงคนในคิวที่ **ถึงเกณฑ์** ขึ้นวาง (ถ้ายังไม่มีใครถึง จะดึงคนที่รอนานสุดขึ้นก่อน เฉพาะกรณีเวทียังว่างหมด)

---

## 4) สิ่งที่ต้องรู้เรื่อง "คนออกไป"

TikTok **ไม่มีเหตุการณ์ "ผู้ใช้ออกจาก LIVE"** เลย เกมส์จึงเดาว่าคนออกไปจาก 2 ทาง:

1. **เงียบไป** — ขึ้นเวทีแล้วไม่แชท/ไม่ไลก์/ไม่ส่งของขวัญ นานกว่า `leaveInactiveSeconds` → ว๊าปหาย
2. **จำนวนผู้ชมห้องลดลง** — ตัวเลข `roomUser` จาก TikTok ลดลงกี่คน ก็ไล่คนออกกี่คน (เอาคนที่คะแนนต่ำสุดออกก่อน)

ปรับ `leaveInactiveSeconds` ได้ที่แผงควบคุม ถ้าไม่อยากให้คนหายเร็วเกินไป

## 5) เปลี่ยนธีมเวที

ภาพพื้นหลังอยู่ที่ `public/assets/bg-stage.jpg` (ตอนนี้เป็นเวทีคอนเสิร์ตไทย ทรงไทย-ทอง-ม) — เอารูปเวทีของคุณไปวางแทนได้เลย (แนะนำ 1920×1080 ขึ้นไป เห็นพื้นที่เวทีว่างด้านล่างสำหรับนักเต้น)

สีชุด/แบบเต้นของนักเต้นกำหนดได้ที่ `public/js/app.js` (`OUTFITS`, `SKINS`) และ `public/css/style.css` (keyframes `dancer-*`, `arm-*`, `leg-*`)

---

## 6) โครงสร้างโค้ด

```
server/
  index.js      HTTP + WebSocket + Admin API
  config.js     ค่าตั้งต้นทั้งหมดของเกมส์
  state.js      หน่วยความจำของผู้ชม/เวที/คิว/แชท
  engine.js     กลไกเกมส์: สะสมเวลา → เลื่อนขึ้นเวที → ไล่คนออก
  tiktok.js     ตัวเชื่อม TikTok LIVE → เกมส์ (reconnect อัตโนมัติ)
  simulator.js  ปลอมผู้ชมสำหรับทดสอบ
public/
  index.html    หน้าเกมส์ (เวทีคอนเสิร์ต + นักเต้น)
  admin.html    แผงควบคุม
  css/style.css ธีมเวที + อนิเมชันนักเต้น 4 แบบ
  js/app.js     วาดเวที/นักเต้น/คิว/แชท/อนิเมชัน
  js/admin.js
  assets/       พื้นหลังเวที + รูปโฮสต์เริ่มต้น
```

เปิดหลายเบราว์เซอร์พร้อมกันก็ได้ — ทุกตัว sync กันผ่าน WebSocket (`/ws`)

## 7) เอาไปใช้ออนไลน์จริง

```bash
SIGN_API_KEY=xxxx TIKTOK_USERNAME=yourchannel npm start
```

หรือขึ้น server จริง (Railway/Render/VPS) แล้วเปิดผ่าน TikTok LIVE Studio เหมือนกัน — แค่เช็กว่าเครื่องนั้นออกเน็ตถึง TikTok ได้
